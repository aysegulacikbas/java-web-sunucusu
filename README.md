# Java Saf Socket Web Sunucusu

Bu proje, 3. parti hiçbir kütüphane kullanılmadan, tamamen saf Java (`ServerSocket` ve `Socket` sınıfları) kullanılarak geliştirilmiş basit bir HTTP web sunucusudur. 

Kırklareli Üniversitesi Yazılım Mühendisliği Bölümü Nesne Yönelimli Programlama dersi final değerlendirme ödevi kapsamında hazırlanmıştır.

## 🚀 Özellikler
* Harici bir framework veya kütüphane barındırmaz (Saf Java TCP Socket Programlama).
* 1989 portu üzerinden gelen HTTP isteklerini dinler ve yanıtlar.
* Tarayıcı üzerinden erişildiğinde dinamik olarak öğrenci bilgilerini ve biyografiyi içeren şık bir HTML sayfası sunar.
